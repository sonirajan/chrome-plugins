# Chrome Plugins

Collection of personal Chrome extensions.

## Plugins

| Plugin                                                                                                                         | Description                                                                                                                       |
|--------------------------------------------------------------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------------------|
| [new-yahoo-mail-remove-ad](./new-yahoo-mail-remove-ad) - [Claude](https://claude.ai/chat/7b895b6d-21a8-40a7-b78b-990036a7f407) | Removes ads and fixes layout in new Yahoo Mail.                                                                                   |
| [linkedin-cleaner](./linkedin-cleaner) - [Claude](https://claude.ai/chat/274728f5-6d70-4136-bd13-0d6e42743194)                 | Removes distractions from LinkedIn: member profile images, promoted posts, advertisements, and videos.                            |
| [serene-newtab](./serene-newtab) - [Claude](https://claude.ai/chat/2669a896-67d4-4b55-8553-2ef383d5daa7)                       | A minimal new tab with a random full-screen background, 12-hour live clock, date, and a daily focus reminder.                     |
| [query-stripper](./query-stripper)                                                                                             | If the localhost URL has query parameters, strips them and redirects to the clean URL.                                            |
| [yahoo-mail-popup](./yahoo-mail-popup)                                                                                         | Opens Yahoo Mail in a small, dedicated popup window instead of a new tab — one click to open, Esc or the close button to dismiss. |

## Setup

Each plugin folder contains its own `README.md` with setup instructions.
